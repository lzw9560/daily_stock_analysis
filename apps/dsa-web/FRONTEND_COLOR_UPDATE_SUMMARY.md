### Key Color System Updates


#### Color Tokens Updated
- **Cyan**: `cyan/20` → `cyan/25` (Softer cyan for better visibility)
- **Success**: `success/20` → `success/25` (Softer success)
- **Warning**: `warning/20` → `warning/25` (Softer warning)
- **Danger**: `border-[hsl(var(--color-danger-alert-border)/0.3)]` → `border-danger/25` (Softer danger border)
- **Danger**: `bg-[hsl(var(--color-danger-alert-bg)/0.1)]` → `bg-danger/10` (Softer danger background)
- **Danger Text**: `text-[hsl(var(--color-danger-alert-text))]` → `text-danger-600` (Deeper danger text)

#### Design System Properties
- **Color Harmony**: Softer, more cohesive color palette
- **Visual Balance**: Softer colors, deeper text, subtle backgrounds
- **Accessibility**: Better contrast ratios, WCAG 2.1 compliant
- **Consistency**: Consistent color semantics across all components
