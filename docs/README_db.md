## 1. 文档概述

### 1.1 文档目的

本文档为"板王助手"打板辅助软件的产品需求规格说明书，用于指导产品设计、开发、测试及后续迭代。

### 1.2 读者对象

- 产品经理
- UI/UX设计师
- 前端/后端开发工程师
- 测试工程师
- 项目管理人员

### 1.3 术语表

| 术语     | 定义                                               |
| -------- | -------------------------------------------------- |
| 打板     | 在股票涨停价买入的行为                             |
| 首板     | 个股在10-20个交易日内的第一个涨停板                |
| 连板     | 连续多个交易日涨停                                 |
| 炸板     | 涨停板被打开，股价回落                             |
| 烂板     | 涨停后反复开板，封单不坚决                         |
| 弱转强   | 前一日表现弱势，次日超预期强势                     |
| 排板     | 提前挂涨停价排队等待成交                           |
| 扫板     | 涨停瞬间以涨停价直接买入                           |
| 封单     | 涨停价位上的买入挂单数量                           |
| 情绪周期 | 市场短线情绪的波动周期（冰点→启动→发酵→高潮→退潮） |
| Level-2  | 交易所提供的逐笔成交明细数据                       |

## 2. 产品背景与目标

### 2.1 市场背景

- A股市场涨停板制度下，短线打板是重要交易策略
- 现有工具（同花顺、通达信）功能泛化，缺乏针对打板的专项辅助
- 打板成功率受情绪、题材、资金、技术等多因素影响，人工判断难度大
- 散户常因信息滞后、情绪干扰导致高买低卖

### 2.2 产品愿景

> 打造最专业的打板决策辅助系统，让每一次打板都有据可依，让空仓也是一种策略。

### 2.3 核心目标

| 目标编号 | 目标描述           | 衡量指标                             |
| -------- | ------------------ | ------------------------------------ |
| G1       | 提高用户打板封板率 | 封板率从行业平均60%提升至75%+        |
| G2       | 降低炸板亏损       | 炸板后次日平均亏损控制在-3%以内      |
| G3       | 优化仓位管理       | 帮助用户保持合理现金比例（建议≥50%） |
| G4       | 提升决策效率       | 从发现信号到下单决策时间<30秒        |
| G5       | 培养交易纪律       | 通过系统约束减少情绪化交易           |

### 2.4 产品定位

- **不做**：自动交易软件、荐股软件、保证收益的承诺
- **只做**：数据整合、信号提示、风险评估、仓位管理的决策辅助工具
- **核心差异**：强调"什么时候不该打"比"什么时候该打"更重要

## 3. 用户画像

### 3.1 主要用户群体

#### 用户A：经验型打板选手（核心用户）

- **年龄**: 28-40岁
- **经验**: 2-5年短线交易经验
- **资金**: 50-200万
- **痛点**: 
  - 信息太多，无法快速筛选有效信号
  - 情绪干扰，明知不该买还是忍不住
  - 仓位管理混乱，经常满仓被套
- **需求**: 快速信号筛选、情绪周期判断、强制仓位提醒

#### 用户B：进阶学习者（潜力用户）

- **年龄**: 25-35岁
- **经验**: 6个月-2年，正在学习打板
- **资金**: 10-50万
- **痛点**:
  - 不懂如何判断封板质量
  - 不知道何时该空仓
  - 缺乏系统的复盘方法
- **需求**: 教学引导、评分解释、历史回测学习

#### 用户C：稳健型投资者（扩展用户）

- **年龄**: 35-50岁
- **经验**: 5年以上，但以价值投资为主
- **资金**: 200万+
- **痛点**:
  - 想尝试短线但担心风险
  - 需要严格的止损机制
- **需求**: 低风险信号、严格风控、现金管理

### 3.2 用户场景

**场景1：盘前准备（8:00-9:15）**
用户：经验型选手
行为：打开软件，查看"今日题材雷达"和"候选股票池"
期望：5分钟内确定今日关注标的和策略

**场景2：盘中决策（9:30-10:30）**
用户：所有用户
行为：收到自选股涨停预警，查看"封板质量评分"
期望：30秒内判断是否值得打板

**场景3：炸板应对（盘中任意时间）**
用户：已持仓用户
行为：收到"炸板风险警报"
期望：立即知道该持有、减仓还是清仓

**场景4：盘后复盘（15:00-18:00）**
用户：进阶学习者
行为：查看"今日操作回顾"和"策略优化建议"
期望：了解今日得失，优化明日策略

**场景5：仓位调整（每日收盘后）**
用户：稳健型投资者
行为：查看"清仓计划助手"
期望：获得具体的减仓/清仓建议

### 4.2 M1 智能打板信号系统

#### 4.2.1 M1.1 盘前题材雷达

**功能描述**: 每日开盘前自动扫描市场信息，识别当日最强题材主线。

**输入数据**:

- 隔夜政策/新闻（证监会、国务院、部委文件）
- 美股/港股相关板块表现
- 期货/大宗商品价格变动
- 昨日涨停股题材归类及溢价率
- 社交媒体热度（雪球、东方财富股吧）

**处理逻辑**:

```
题材热度评分 = 政策权重 x 30% + 新闻权重 x 25% + 美股映射 x 15% + 昨日溢价 x 20% + 社交热度 x 10%
```

**输出内容**:

| 字段       | 说明                        |
| ---------- | --------------------------- |
| 题材名称   | 如"商业航天"、"深海经济"    |
| 热度评分   | 0-100分                     |
| 核心标的   | 该题材的前3只龙头股         |
| 催化事件   | 触发该题材的具体新闻/政策   |
| 持续性预判 | 短期（1-3天）/中期（1-2周） |
| 关联板块   | 上下游产业链相关板块        |

**界面元素**:

- 题材热度排行榜（TOP10）
- 每个题材的可展开详情面板
- "一键加入自选"按钮

**优先级**: P0（核心功能）

#### 4.2.2 M1.2 候选股票池

**功能描述**: 根据预设策略自动生成今日打板候选股票池。

**股票池基础筛选（打板八项标准）**:

所有候选池均默认过滤以下不符合八项标准的股票，用户可在设置中关闭部分条件：

| 八项标准    | 系统筛选条件                | 说明                                     |
| ----------- | --------------------------- | ---------------------------------------- |
| 1. 流通市值 | 30亿–150亿                  | <30亿庄股风险高，>200亿游资拉不动        |
| 2. 换手率   | 5%–20%                      | <5%缩量没人接，>20%分歧过大易炸          |
| 3. 量能比   | 封板前量能 > 前5日均量1.5倍 | 必须放量，缩量板次日无溢价               |
| 4. 封板时间 | 10:30前封板                 | 主力态度坚决，尾盘板放弃                 |
| 5. 开板次数 | ≤1次                        | 0次最佳，1次回封可接受，≥2次自动排除     |
| 6. 封单金额 | >流通市值1%                 | 如50亿市值需>5000万封单                  |
| 7. 题材热度 | 属于当日题材雷达TOP10       | 无热点不溢价                             |
| 8. 股价位置 | 低位首板或平台突破          | 二板以上需人工确认，三板以上系统标红警告 |

**股票池分类**:

| 池名称     | 筛选条件                                      | 适用策略                         |
| ---------- | --------------------------------------------- | -------------------------------- |
| 首板候选池 | 昨日首板+今日高开3%+量比>3+符合八项标准       | 首板战法                         |
| 连板候选池 | 昨日连板+竞价封单>5万手+板块效应+符合八项标准 | 龙头战法                         |
| 弱转强池   | 昨日烂板+今日竞价高开5%+快速拉升+符合八项标准 | 弱转强战法                       |
| 反包候选池 | 前日断板+今日低开高走+放量+符合八项标准       | 反包战法                         |
| 自选预警池 | 用户自选股触及涨停价                          | 个性化跟踪（不强制过滤八项标准） |

**每只股票展示信息**:

- 股票名称、代码、所属题材
- 现价、涨幅
- 涨停时间
- 封单量、封单金额
- 封板评分（0-100分）
- 昨日表现（首板/连板/烂板）
- 板块联动（同板块涨停数量）
- 操作按钮（查看详情/加入自选/模拟买入）

**更新频率**: 实时（每秒刷新）

**优先级**: P0

#### 4.2.3 M1.3 实时封板质量评分

**功能描述**: 对每只涨停股票进行多维度量化评分，辅助用户判断封板质量。

**评分维度与权重**:

| 维度     | 权重 | 评分标准                                                     | 数据来源    |
| -------- | ---- | ------------------------------------------------------------ | ----------- |
| 涨停时间 | 20%  | 9:30-9:45(20分) 9:45-10:00(15分) 10:00-10:30(10分) 10:30后(5分) | Level-2行情 |
| 封单金额 | 15%  | >流通市值2%(15分) >1%(10分) >0.5%(5分) <0.5%(0分)            | 实时盘口    |
| 板块联动 | 15%  | 同板块>=5只涨停(15分) >=3只(10分) >=1只(5分) 无(0分)         | 板块数据    |
| 量能健康 | 15%  | 封板前30分钟量>=前5日均量50%(15分) >=30%(10分) >=10%(5分)    | 历史+实时   |
| 均线形态 | 10%  | 5/10/20日线全向上(10分) 5/10向上(7分) 仅5日向上(3分)         | K线数据     |
| 资金性质 | 10%  | 游资+机构合力(10分) 纯游资(7分) 纯散户(3分)                  | 龙虎榜+盘口 |
| 大盘环境 | 10%  | 指数涨幅>0.5%(10分) -0.5%~0.5%(7分) <-0.5%(3分)              | 指数数据    |
| 连板高度 | 5%   | 首板(5分) 二板(4分) 三板(3分) 四板+(2分)                     | 连板数据    |

**评分等级**:

| 分数   | 等级 | 颜色      | 建议                   |
| ------ | ---- | --------- | ---------------------- |
| 85-100 | 极佳 | 红色      | 强烈推荐，可大仓位参与 |
| 70-84  | 良好 | 浅红/粉红 | 推荐参与，正常仓位     |
| 55-69  | 一般 | 黄色      | 谨慎参与，小仓位试错   |
| 40-54  | 较差 | 橙色      | 不建议参与，观望为主   |
| 0-39   | 危险 | 绿色      | 强烈不建议，可能炸板   |

**动态更新**: 评分每30秒重新计算，封单变化、板块异动、大盘波动都会实时影响评分。

**优先级**: P0

#### 4.2.4 M1.4 炸板风险预警

**功能描述**: 对已封板股票进行实时监控，提前预警炸板风险。

**预警触发条件**（满足任一即触发）:

| 条件编号 | 触发条件                    | 预警级别 |
| -------- | --------------------------- | -------- |
| C1       | 封单金额在5分钟内减少>30%   | 黄色预警 |
| C2       | 出现单笔>5000手卖单砸盘     | 黄色预警 |
| C3       | 同板块龙头股炸板            | 红色预警 |
| C4       | 大盘5分钟内急跌>0.5%        | 红色预警 |
| C5       | 涨停板被打开且3分钟内未回封 | 红色预警 |
| C6       | 封单金额<流通市值0.3%       | 红色预警 |

**预警响应**:

**黄色预警**:

- 弹窗提示 + 声音提醒
- 显示风险原因
- 建议: "密切关注，准备减仓"

**红色预警**:

- 弹窗提示 + 声音提醒
- 显示风险原因 + 关联影响
- 建议: "建议立即减仓或清仓"
- 提供"交易价格提醒"功能：用户可设置目标卖出价位，当股价触及该价位时推送提醒（本系统不执行任何交易指令，仅提供价格监控提醒）

**优先级**: P0

#### 4.2.5 M1.5 打板八项标准检查表

**功能描述**: 将八项标准固化成系统化的决策约束工具，强制用户在下单前逐条确认，解决"复盘时清醒、盘中手痒"的人性弱点。

**检查表界面**:

```
+-----------------------------------------+
| 打板决策检查表 — [巨力索具] 002342      |
+-----------------------------------------+
| 下单前必须全部勾选（系统根据数据自动预填） |
|                                         |
| [✓] 1. 流通市值 87亿（30-150亿范围内）  |
| [✓] 2. 换手率 12.3%（5%-20%范围内）    |
| [✓] 3. 量能比 2.1倍（>1.5倍）          |
| [✓] 4. 封板时间 09:47（<10:30）        |
| [✓] 5. 开板次数 1次（≤1次）            |
| [✗] 6. 封单金额 3200万（需>5000万）    |
| [✓] 7. 题材热度：商业航天（TOP3）      |
| [✓] 8. 股价位置：平台突破              |
|                                         |
| 结果：1项未通过（封单金额不足）          |
| 系统建议：不符合八项标准，建议放弃       |
|                                         |
| [我已了解风险，仍要关注] [放弃，看其他]  |
+-----------------------------------------+
```

**强制约束机制**:

| 场景         | 系统行为                                   |
| ------------ | ------------------------------------------ |
| 八项全部通过 | 显示"符合标准"，封板评分正常计算           |
| 1-2项未通过  | 标黄警告，显示未通过项的具体数据           |
| ≥3项未通过   | 标红警告，封板评分上限锁定为55分           |
| 三板以上股票 | 无论是否通过，均弹窗警告"高位接力风险极高" |

**用户行为记录**:

- 记录用户每次是否严格按八项标准执行
- 统计"违反标准后的炸板率" vs "严格执行后的炸板率"
- 在绩效分析中增加"八项标准遵守率"维度

**次日卖出纪律提醒**:

| 次日情况    | 系统提醒                   |
| ----------- | -------------------------- |
| 高开 ≥ 4%   | "建议分批卖出，不要等涨停" |
| 平开 / 低开 | "15分钟不翻红请果断离场"   |
| 低开 > 2%   | "竞价弱势，建议开盘即走"   |

**优先级**: P0（核心功能）

### 4.3 M2 情绪周期仪表盘

#### 4.3.1 M2.1 情绪指标计算

**功能描述**: 通过多维度数据计算市场短线情绪状态。

**核心指标**:

| 指标         | 计算方法                   | 正常范围 | 极端值                   |
| ------------ | -------------------------- | -------- | ------------------------ |
| 涨停家数     | 当日涨停股票数量           | 30-80家  | <20家(冰点) >150家(高潮) |
| 跌停家数     | 当日跌停股票数量           | 0-10家   | >30家(恐慌)              |
| 连板高度     | 市场最高连板数             | 3-6板    | 2板(低迷) >8板(过热)     |
| 炸板率       | 炸板数/曾涨停数            | 15%-30%  | >40%(弱势) <10%(极强)    |
| 昨日涨停溢价 | 昨日涨停股今日平均涨幅     | +2%~+5%  | <0%(退潮) >+7%(高潮)     |
| 连板晋级率   | 昨日连板股今日继续涨停比例 | 40%-60%  | <20%(冰点) >80%(过热)    |
| 量能变化     | 两市成交额环比             | +-10%    | >+30%(放量) <-20%(缩量)  |

**情绪指数公式**:

```
情绪指数 = 涨停家数标准化 x 20% + (100-跌停家数标准化) x 15% + 连板高度标准化 x 15% + (100-炸板率标准化) x 15% + 昨日涨停溢价标准化 x 15% + 连板晋级率标准化 x 15% + 量能变化标准化 x 5%
```

**输出**: 0-100分的情绪指数

**优先级**: P1

```python
def calculate_score(stock_data, market_data):
    # 封板质量评分算法
    # 输入: 个股实时数据 + 市场数据
    # 输出: 0-100分的评分
    score = 0

    # 1. 涨停时间 (20%)
    time_score = calculate_time_score(stock_data['limit_up_time'])
    score += time_score * 0.20

    # 2. 封单金额 (15%)
    order_score = calculate_order_score(
        stock_data['seal_amount'], 
        stock_data['circulating_market_cap']
    )
    score += order_score * 0.15

    # 3. 板块联动 (15%)
    sector_score = calculate_sector_score(
        stock_data['sector'],
        market_data['sector_limit_up_count']
    )
    score += sector_score * 0.15

    # 4. 量能健康 (15%)
    volume_score = calculate_volume_score(
        stock_data['pre_limit_volume'],
        stock_data['avg_volume_5d']
    )
    score += volume_score * 0.15

    # 5. 均线形态 (10%)
    ma_score = calculate_ma_score(stock_data['ma5'], stock_data['ma10'], stock_data['ma20'])
    score += ma_score * 0.10

    # 6. 资金性质 (10%)
    fund_score = calculate_fund_score(stock_data['main_force_ratio'])
    score += fund_score * 0.10

    # 7. 大盘环境 (10%)
    market_score = calculate_market_score(market_data['index_change'])
    score += market_score * 0.10

    # 8. 连板高度 (5%)
    height_score = calculate_height_score(stock_data['consecutive_limit_up'])
    score += height_score * 0.05

    return round(score)
```

#### 8.3.2 情绪周期判断算法

```python
def calculate_sentiment(market_data):
    # 情绪周期判断
    # 输入: 市场综合数据
    # 输出: 情绪指数(0-100) + 周期阶段

    # 标准化各指标到0-100
    limit_up_norm = normalize(market_data['limit_up_count'], 0, 150)
    limit_down_norm = 100 - normalize(market_data['limit_down_count'], 0, 50)
    height_norm = normalize(market_data['max_height'], 1, 10)
    bomb_norm = 100 - normalize(market_data['bomb_rate'], 0, 50)
    premium_norm = normalize(market_data['avg_premium'], -5, 10)
    advance_norm = normalize(market_data['advance_rate'], 0, 100)

    # 加权计算
    sentiment = (
        limit_up_norm * 0.20 +
        limit_down_norm * 0.15 +
        height_norm * 0.15 +
        bomb_norm * 0.15 +
        premium_norm * 0.15 +
        advance_norm * 0.15 +
        normalize(market_data['volume_change'], -30, 50) * 0.05
    )

    # 判断周期阶段
    if sentiment <= 20:
        phase = "冰点期"
    elif sentiment <= 40:
        phase = "启动期"
    elif sentiment <= 60:
        phase = "发酵期"
    elif sentiment <= 80:
        phase = "高潮期"
    else:
        phase = "退潮期"

    return sentiment, phase
```

#### 8.3.3 炸板风险预警算法

```python
def detect_bomb_risk(stock_data, market_data):
    # 炸板风险检测
    # 返回: (风险等级, 风险原因列表)
    risks = []
    level = 0  # 0=无风险, 1=黄色, 2=红色

    # 条件1: 封单快速减少
    if stock_data['seal_amount_change_5m'] < -0.3:
        risks.append("封单金额5分钟内减少>30%")
        level = max(level, 1)

    # 条件2: 大单砸盘
    if stock_data['big_sell_order'] > 5000:
        risks.append("出现单笔大卖单砸盘")
        level = max(level, 1)

    # 条件3: 同板块龙头炸板
    if market_data['sector_leader_bombed']:
        risks.append("同板块龙头已炸板")
        level = max(level, 2)

    # 条件4: 大盘急跌
    if market_data['index_drop_5m'] > 0.5:
        risks.append("大盘5分钟内急跌")
        level = max(level, 2)

    # 条件5: 已炸板未回封
    if stock_data['is_bombed'] and stock_data['bomb_duration'] > 180:
        risks.append("涨停板已打开且3分钟内未回封")
        level = max(level, 2)

    # 条件6: 封单极低
    if stock_data['seal_amount'] < stock_data['circulating_market_cap'] * 0.003:
        risks.append("封单金额<流通市值0.3%")
        level = max(level, 2)

    return level, risks
```
